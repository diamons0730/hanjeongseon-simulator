# 한정선 시뮬레이터

HTML, CSS, Vanilla JavaScript로 만든 따뜻한 2D 떡집 경영 게임입니다. 외부 이미지나 3D 라이브러리 없이 CSS 도형과 캐릭터로 매장을 표현합니다. 재료 발주와 손질, 드래그 제조, 손님 응대, 결제, 마감 정산과 업그레이드를 진행할 수 있습니다.

## 프로젝트 구조

```text
한정선/
├── index.html                 # 게임 화면과 인터페이스
├── styles.css                 # 2D 매장 장면, 캐릭터와 반응형 디자인
├── script.js                  # 영업 루프, 난이도, 랭킹과 상호작용
├── manifest.json              # PWA 설치 정보
├── service-worker.js          # 앱 셸 오프라인 캐시
├── icons/icon.svg             # PWA 아이콘
├── capacitor.config.json      # Capacitor 앱 설정
├── package.json               # 웹 개발과 Android 빌드 명령
└── scripts/build.mjs          # Capacitor용 www/ 자산 복사
```

## 실행하기

Node.js 20 이상을 설치하고 프로젝트 폴더에서 실행합니다.

```powershell
npm install
npm run dev
```

Vite가 출력하는 로컬 주소로 접속하세요. `file://`로 직접 열면 Service Worker와 PWA 기능이 제한되므로 로컬 웹 서버를 사용해야 합니다. 게임 자체는 외부 라이브러리 없이 동작하며, 글꼴은 인터넷이 연결된 경우 Google Fonts를 사용합니다.

## 게임 진행

- **재료 구매:** 시작 자금으로 재료상에서 찹쌀떡 피, 팥소, 요거트 소, 딸기·망고·청포도·복숭아·키위, 보자기를 1개 또는 3개 단위로 삽니다. 매일 표시되는 예상 소요량을 확인하세요. 남은 재료와 재고는 다음 날로 이어집니다.
- **오픈 준비:** 그날 손님의 과일 주문을 확인하고 해당 과일을 작업대 손질판으로 드래그해 준비합니다. 주문량에 맞는 재료를 확보하고 주문 과일을 손질해야 영업을 시작할 수 있습니다.
- **영업 및 드래그 제조:** 손님 주문을 받은 뒤 재료를 작업판으로 직접 끌어 놓습니다. 순서는 찹쌀떡 피 → 주문된 팥소 또는 요거트 소 → 주문 과일 → 보자기이며, 2개 주문은 앞의 세 단계를 두 번 반복합니다. 재료를 잘못 놓으면 손님 인내심이 4초 감소합니다. 마우스·터치 드래그를 지원하며, 키보드/보조 입력은 재료 선택 후 작업판을 누르면 됩니다.
- **튜토리얼:** 첫 실행 시 구매부터 정산까지 5단계 안내가 나옵니다. 상단 도움말에서 언제든 다시 볼 수 있습니다.
- **손님 안정성:** 손님 캐릭터는 DOM에서 재사용되어 대기 타이머가 갱신되어도 깜박이지 않습니다.
- **결제 및 마감:** 떡을 완성하면 POS에서 결제합니다. 손님이 모두 돌아가면 카운터 청소를 세 번 완료해 정산 화면으로 이동합니다.
- **난이도:** DAY가 오를수록 손님이 늘고 대기 인내심이 줄어듭니다. 이탈은 평판을 낮추며, 빠른 응대는 평판 보너스를 줍니다.
- **정산 및 성장:** 이름과 오늘의 기록은 브라우저당 한 번만 로컬 TOP 5에 등록할 수 있습니다. 첫 등록 후에도 다음 날 영업을 계속할 수 있지만, 랭킹 이름·점수는 다시 제출되지 않습니다. 정산 시 웨이팅 의자, 고급 과일 칼, 실크 보자기를 구매할 수 있습니다.

마우스 또는 터치 드래그로 재료를 옮기는 2D 인터페이스로 플레이합니다. 튜토리얼 완료 여부와 랭킹은 현재 브라우저의 `localStorage`에 저장되며, 랭킹은 이 기기와 브라우저에만 유지됩니다. 다른 사람이 인터넷으로 접속해 플레이할 수 있도록 하려면 HTTPS 정적 호스팅에 배포해야 합니다. 현재 랭킹은 서버에 연결되어 있지 않아 플레이어들 간에 공유되지 않습니다. 게임 재화와 재료 재고는 현재 페이지를 새로 고침하면 초기화됩니다.

## PWA 설치

HTTPS 배포 후 지원 브라우저의 앱 설치 메뉴를 이용하세요. 서비스 워커는 HTML, CSS, JavaScript, 매니페스트와 아이콘을 캐시합니다.

## Android APK 빌드

Android Studio와 Android SDK를 설치하고 프로젝트 폴더에서 실행합니다.

```powershell
npm install
npx cap add android
npm run android:apk
```

디버그 APK는 `android/app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 웹 코드를 수정한 뒤에는 `npm run cap:sync`로 자산을 복사하고 동기화할 수 있습니다. Android Studio 프로젝트는 `npm run android:open`으로 엽니다. 서명 APK/AAB는 Android Studio의 **Build > Generate Signed Bundle / APK**에서 생성하세요.
